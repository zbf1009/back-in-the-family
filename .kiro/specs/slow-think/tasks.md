# Implementation Plan: slow-think

## Overview

Spec 7 wires the production D decision path without making the model part of the simulation. It exposes the existing pure preview/renderer/validator seam through WASM, adds a browser Decision_Bridge and same-origin Decision_Worker, records decision provenance and exports actual runs in replay v5 for audit, and prepares separately gated hosted and artifact releases.

The plan is serial and has five Author checkpoints:

1. **C1 — pure bridge seam (2.1):** native/WASM preview/render/validate and audit-export parity, fingerprint neutrality and protected-file proof; no network.
2. **C2 — local integration (4.3):** fake AI, actual local Worker routing, browser recovery, offline replay and metrics; no live model.
3. **C3 — bounded measurement (5.2):** report one authorized local-first browser attempt and its export, then STOP. Selecting the measured public limit is a separate leaf (5.3).
4. **C4 — disposable Deploy-button trial (7.2):** separately authorized throwaway branch, Worker and bounded call, with cleanup; STOP before permanent publisher/button rollout.
5. **C5 — independent audit (9.2):** report offline and live evidence separately, including any blocked or unverified outcomes, then STOP.

Neither the hosted rollout nor the permanent publisher rollout is implied by this plan. No B-direction redesign or presentation text is included.
